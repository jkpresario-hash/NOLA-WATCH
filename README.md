# NOLA WATCH

뉴올리언스 펠리컨스 Reddit·뉴스·YouTube·아티클을 한국어로 읽는 GitHub Pages 피드. 첫 페이지는 뉴스이며 전체 모음 탭은 제공하지 않습니다.

## 기능
- 첨부 허용 목록(news_sources.json)에 있는 소스만 site: 조건으로 검색. RSS 발행 매체, 실제 기사 주소와 리디렉션도 확인하며 목록 밖 뉴스는 기존 피드에서도 제외
- r/NOLAPelicans는 최신순 목록에서 뉴스·잡담·밈·이미지·영상·질문 등 주제 구분 없이 공개 게시글 수집. 뉴스용 키워드·중계 스팸 필터를 Reddit에 적용하지 않음
- 한국어 제목, 기사 본문의 주요 문장 3개를 발췌한 한국어 요약
- Reddit 텍스트 본문과 상위 댓글 최대 10개 번역, 댓글별 원문 링크
- 원문 OG 이미지·Reddit 미리보기 썸네일 (없는 이미지나 로딩 실패 이미지 숨김)
- Reddit / 뉴스 / YouTube / 아티클의 4개 탭, 한·영 검색, 모바일 레이아웃, 20개씩 더 보기
- 하루 두 번 한국어·영어로 펠리컨스 YouTube 검색, 자막 또는 영상 설명의 서로 다른 핵심 내용 3개 이상을 발췌해 한국어 번역
- 한국시간 09:00 / 18:00 GitHub Actions 수집 및 Pages 배포

## 실행
Python 3.12 환경에서:
```
pip install -r requirements.txt
python -m unittest discover -s tests
node --test tests/feed.test.js
python collect.py --limit 40
python -m http.server 8000
```
브라우저에서 http://localhost:8000 을 엽니다. `collect.py`는 data.json만 갱신하므로 화면 파일을 덮어쓰지 않습니다.

## 운영상 제한
번역에는 API 키 없이 접근 가능한 Google Translate 웹 엔드포인트를 사용합니다. 정식 SLA가 있는 API가 아니며 이용량 제한이나 서비스 변경으로 실패할 수 있습니다. 실패는 원문 링크와 함께 표시되며 다음 수집에서 재시도합니다. 상용 규모 운영에는 정식 번역 API로 교체하는 것을 권장합니다.

기사 요약은 생성형 요약이 아닌 주요 문장 발췌 번역입니다. 유료벽·차단·본문 추출 실패 시 제목만 번역될 수 있습니다. Google News 원문 주소 해석도 외부 서비스 동작에 의존합니다. Reddit JSON API 실패 시 공개 댓글 RSS로 대체 수집합니다. 두 경로 모두 실행 환경 IP에 따라 403/429를 반환할 수 있으며 이 경우 본문·댓글 번역이 제공되지 않습니다. RSS는 추천 수를 제공하지 않으며 피드에 포함된 댓글 최대 10개를 표시합니다. 전체 댓글이 아니라 API가 반환하는 상위 댓글 최대 10개입니다.

제목과 저장된 본문·댓글은 본문 수집 한도와 별도로 번역합니다. 뉴스·Reddit 본문 수집은 실행당 최대 200개, 7분 30초의 예산으로 처리하고 기존 성공 번역과 번역 캐시를 재사용합니다. YouTube에는 별도 3분의 수집 예산을 둡니다. Reddit 댓글은 6시간 이상 경과하면 다시 수집합니다. data.json에는 뉴스는 최근 200개까지, 수집된 Reddit 게시글은 개수 제한 없이 유지하며 수집 실패 시 기존 데이터와 성공한 번역을 유지합니다. 아직 시도하지 않은 글부터 처리하고 실패 항목은 6시간 이후 재시도합니다. 제목 번역과 본문·댓글 수집 실패는 별도로 기록합니다. 실행 일정은 GitHub에 의해 지연될 수 있습니다.

GitHub Pages 설정은 기존처럼 Source: GitHub Actions를 유지합니다. 수집기·화면·테스트·워크플로 변경을 main에 반영하면 테스트 후 자동 수집·배포합니다. 데이터만 저장하는 자동 커밋은 재실행을 유발하지 않습니다. Actions → Update NOLA WATCH → Run workflow로 수동 실행하거나 정기 실행을 기다릴 수도 있습니다. 번역 캐시는 GitHub Actions cache에 저장되며 공개 사이트 파일에 포함되지 않습니다.


## Reddit 수집 범위

인기순 대신 `/new/.rss?limit=100`을 사용합니다. 페이지당 최대 100개를 읽고 기존에 수집한 게시글에 닿을 때까지 다음 페이지를 확인합니다. 겹치는 페이지도 모든 게시글을 저장하고, 제목이나 주소의 표기가 달라도 Reddit 게시글 ID로 중복을 제거합니다. 실행당 최대 10페이지이며 페이지 한도·접근 오류·반복 페이지는 피드에 경고로 표시합니다. 중간 페이지가 실패해도 앞서 수집한 글과 기존 글을 유지합니다. 중단된 페이지 커서는 data.json에 저장하고, 다음 실행에서 새 글 확인과 함께 남은 페이지 수집을 재개합니다.

현재 공개 목록에 제공되는 글을 시작으로 이후 새 글을 수집하는 방식입니다. Reddit이 목록에 제공하지 않는 과거 전체 이력, 삭제·비공개 글, 접근 차단 중 올라왔다가 사라진 글까지 완전한 수집을 보장하지는 않습니다. 본문·댓글 번역은 기존 방식으로 계속 수행합니다.

## 뉴스 소스 및 언어 정책

news_sources.json이 뉴스 허용 소스의 단일 기준입니다. NOLA.com, The Athletic, HoopsRumors, RealGM/SportSpyder, Pelicans Report, Pelican Debrief/The Bird Writes 및 첨부된 한국어·일본어·중국어 매체와 커뮤니티만 검색합니다. The Athletic은 NYTimes의 /athletic 경로, Sporting News는 /jp/nba, 네이버는 점프볼(065)·루키(398), 디시인사이드는 NBA 갤러리로 제한합니다. Reddit은 별도 최신순 전체 글 수집을 유지합니다. YouTube는 social_sources.json의 별도 범위를 사용하며 뉴스 중복·소스 정책을 적용하지 않습니다.

영어를 우선 보관하고, 한·중·일어는 영어로 비교용 제목을 번역해 72시간 이내 제목의 핵심 단어·사건·숫자를 비교합니다. 영어 기사 또는 영어 Reddit 글과 중복되는 비영어 기사는 제외하며, 같은 선수라도 사건이나 점수가 다르면 구분합니다. 동일 URL의 추적 파라미터도 제거해 비교합니다. 새 영어 글이 나중에 발견되면 기존 비영어 중복 글도 다시 정리합니다.

이 비교는 제목에 기반한 규칙 방식이므로 의미상 중복을 완벽히 판정하지는 못합니다. 영어 소스 검색이 실패하거나 비교용 번역을 얻지 못하면 비영어 글은 deferred_news에 보관해 재시도하고 공개 피드에서는 제외합니다. 본문 수집이 차단된 경우 허용된 매체의 제목만 제공될 수 있습니다. Google 검색에 색인되지 않은 게시글이나 각 사이트에서 공개하지 않는 자료의 완전한 수집은 보장하지 않습니다.

최신 피드에서는 발행일이 확인된 최근 7일 기사만 남기고, 목차·선수 소개·경기 박스스코어 페이지는 제외합니다. 비영어 제목의 버프킨(Bufkin/Bavkin), waive/wave 같은 번역 표기도 정규화합니다. 영어 본문을 읽을 수 있으면 선수·사건의 짧은 식별 정보만 저장해 단신 모음 기사에 이미 나온 소식도 중복 비교에 사용하며, 기사 전체 본문은 저장하지 않습니다. 본문 수집 뒤 중복을 한 번 더 검사합니다.

후푸는 게시글의 '发表在' 게시판 표시가 pelicans(鹈鹕专区)인지 확인하며, 다른 팀 게시판이나 공통 NBA 게시판 글은 제외합니다. 바이두는 鹈鹕吧를 확인합니다. 게시판 출처를 검증하지 못한 글도 공개하지 않고 deferred_news에서 재시도합니다.

## YouTube 검색·요약

매일 한국시간 09:00·18:00에 `뉴올리언스 펠리컨스`와 `New Orleans Pelicans`를 검색합니다. 공식 API는 최신순, 공개 검색은 최근 1주·동영상 필터를 사용합니다. 검색어당 최대 20개의 최근 영상을 확인하고 영상 ID로 중복 제거하며 최신 200개를 유지합니다. 펠리컨스 언급이 제목·검색 설명에서 확인된 영상만 추가합니다. YouTube가 공개 검색의 업로드일 정렬을 제거했으므로 공식 API 없이 검색한 결과의 최신순 완전성은 보장하지 않습니다.

기본 검색은 공개 YouTube 검색을 사용합니다. 공식 검색을 사용하려면 Google Cloud에서 YouTube Data API v3를 활성화한 API 키를 `YOUTUBE_API_KEY`라는 Actions Secret으로 등록합니다. 이 키는 영상 검색·설명을 가져오는 용도이며 비공개 자막 접근 권한을 주지는 않습니다.

공개 자막을 먼저 확인하고, 없거나 접근할 수 없으면 영상 설명을 사용합니다. 서로 다른 원문 내용 3개 이상을 확인해야 한국어 요약으로 표시하며 자막 기반인지 설명 기반인지 구분합니다. 같은 문장을 반복하거나 제목·채널명으로 3개를 채우지 않습니다. 원문 발췌 방식이며 생성형 재작성 요약은 아닙니다. 광고·구독 안내를 제외하고 영상의 앞·중간·뒤 구간에서 핵심 문장을 선택합니다. 영상 설명 기반일 때는 실제 발언 전체를 요약한 것으로 표시하지 않습니다.

자막이 없거나 YouTube가 실행 환경의 접근을 제한하고 설명도 짧으면 영상은 요약 대기로 남습니다. 짧은 하이라이트처럼 내용 3개를 확인할 수 없는 영상의 내용을 추정하지 않습니다. 다음 수집에서 재시도하고 기존 성공 요약은 유지합니다. 검색·수집 상태는 각 탭에 따로 표시합니다.

X 수집 계획은 취소했습니다. 수집 코드·계정 목록·인증 환경변수·탭과 공개 데이터에서 제거했으며 이후 정기 수집도 X에 요청하지 않습니다.

## 분석 아티클 수집

article_sources.json에 선택한 5개 매체(The Hardwood Collective, In The N.O., Basketball Poetry, Swish Theory, No Ceilings)를 기록합니다. Opta Analyst는 추가하지 않습니다. 기존 뉴스 허용 목록과 별개로 관리하며 아티클을 뉴스의 7일 제한·200개 한도에 섞지 않습니다.

매일 한국시간 09:00·18:00에 RSS와 공식 새 글 목록을 직접 확인합니다. Substack의 공개 아카이브 목록, WordPress의 공개 글 목록과 사이트 링크·사이트맵을 함께 사용하며 중단된 과거 목록은 커서를 저장해 이어서 확인합니다. 제목에 팀명이 없어도 본문에 펠리컨스 또는 핵심 선수의 실질적인 분석이 있으면 포함합니다. 메뉴·댓글·추천글·구독 안내는 관련성 검사에서 제외합니다.

발행일이 확인된 최근 90일 글만 아티클 탭에 보관하며 매 실행마다 오래된 글을 제거합니다. 사이트맵의 수정일을 발행일로 대신 사용하지 않습니다. 날짜·본문 확인 실패는 공개 아티클로 확정하지 않고 대기열에 보관합니다. 원문 주소·리디렉션은 해당 매체의 허용 도메인으로 제한하고 중복 주소의 추적 파라미터를 제거합니다.

관련 본문에서 주요 문장을 최대 5개 발췌해 한국어로 번역하고 글쓴이·발행일·원문 링크를 제공합니다. 기사 전체 본문은 공개 데이터에 저장하지 않습니다. 유료벽은 우회하지 않으며 공개 소개문만 확인할 수 있으면 그 범위를 표시합니다. 소개문만으로 관련성을 확인할 수 없으면 보류합니다. 번역 실패는 확인된 원문 요약을 유지해 재시도합니다.

초기 90일 수집은 공개 목록·본문 접근 범위와 실행 시간에 따라 여러 번에 나누어 진행될 수 있습니다. 아티클 수집은 6분, YouTube는 3분, 뉴스·Reddit 본문 갱신은 7분 30초의 예산을 사용하며 실패·남은 글은 다음 실행에서 이어서 확인합니다. 아티클 탭에 소스 접근 지연 및 확인 대기 상태를 표시합니다. 원문 접근 실패 시 기존에 검증된 아티클은 90일 동안 유지합니다.
